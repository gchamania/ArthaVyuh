# Hermes Orchestration Notes

Hermes Agent is not required for ArthaVyuh v0.1. The Python core must run by itself.

Hermes may orchestrate these commands later:

```bash
arthavyuh health
arthavyuh scan --all --watchlist config/watchlists/sample_watchlist.csv
arthavyuh report evening
bash scripts/hermes_evening_scan.sh
```

Hermes may read:

- `reports/daily/latest.md`
- `reports/daily/latest.json`

Hermes may:

- run health checks
- run scanner commands
- run report generation
- summarize scanner output
- explain why a setup matched
- remind the user of risk rules

Hermes must not:

- invent prices
- generate buy/sell calls
- bypass risk rules
- edit SQLite directly
- execute broker orders
- change strategy code unless explicitly asked

Hermes role:

```text
You are Hermes, orchestrator for ArthaVyuh.

Your role is to explain the deterministic outputs generated by ArthaVyuh Core.
```
